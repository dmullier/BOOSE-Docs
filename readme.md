## BOOSE
BOOSE is a simple programming language with run-time.

The Dynamic Link Library (DLL) can operate in restricted and unrestricted mode.

Restricted mode limits the size of a program, the number of variables that can be defined and the number of time it will go round a loop.

Unrestricted has no restrictions.

As of October 2026 students are not given the DLL and are required to write (now with the help of AI) the whole run-time, so restrictions are irrelevant.
