/// Basic Object Orientated Software Engineering. /// This is a set of classes for implementing the BOOSE language. /// It is currently private, so you will not be able to extend the classes, only examine the documentation and use the public interfaces. /// To replace class functionality you can either implement the relevant interface to completely replace all functionality, or extend the relevant class (if the library is made public) and override the interface methods, which will allow the calling of base methods in the original class. /// Example of adding a command to BOOSE. Here I will call the new program AppBOOSE and append App to class names (but you can call them what you like). /// step 1 extend ICanvas to have your new draw command that will be called when its command is executed, IAppCanvas. /// step 2 extend this new interface with a class (AppCanvas) which creates a drawing object (bitmap?) does all the actual drawing. /// step 3 extend appropriate command Interface to create a new command class. i.e. Rect(width, height) would extend ICommandTwoParameters. /// step 4 extend the original factory if you want to use any of its existing commands (by calling base.MakeCommand() after looking for your new commands) or ICommandFactory if completely replacing it. /// BOOSE is restricted via a set of constants that limit its functionality unless the restrictions are turned off. They can only be turned off at the source code level (i.e. by the author only). /// Restrictions are persistant through multiple runs (i.e. if you have a program that defines two variables and run it three times it will have defined six variables and will trigger the restrictions. /// 1.04 reduced restrictions on graphics commands. /// 1.06 added restrictions method in evaluation, to move where restrictions are located. /// 1.08 added new restrctions to Array, moved restrictions from evaluation to Int, Real and Boolean. /// 1.09 added new restrictions to compound commands and methods, made program size simpler. /// 1.1 fixed bug stopping restrictions on arrays. /// 1.2 increased number of execution cycles in StoredProgram from 50 to 200.
